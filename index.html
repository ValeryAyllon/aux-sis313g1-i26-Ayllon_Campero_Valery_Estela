Pregunta 3

Enunciado: Explicar paso a paso la secuencia de comandos para subir cambios al repositorio, empezando desde la clonación del repositorio creado en la pregunta 2.

Respuesta:

Abre la consola o Git Bash en tu computadora y ejecuta la siguiente secuencia de comandos:

a) Clonar el repositorio

git clone https://github.com/TU_USUARIO/aux-sis313g1-i26-APELLIDOS_NOMBRES.git

b) Entrar a la carpeta

cd aux-sis313g1-i26-APELLIDOS_NOMBRES

c) Preparar los archivos (Staging)

git add .

d) Registrar el commit

git commit -m "Primer avance de la materia"

e) Subir los cambios a GitHub

git push origin main

Pregunta 4

Enunciado: Explicar paso a paso cómo realizar el deploy de una página web utilizando GitHub Pages.

Respuesta:

  1. Acceder a la configuración: Ingresa a tu repositorio y abre la pestaña Settings.
  2. Buscar la sección Pages: En el menú lateral izquierdo, selecciona la opción Pages.
  3. Configurar la rama de origen (Branch):
    • En Source, selecciona "Deploy from a branch".
    • En Branch, elige la rama main y carpeta / (root).
    • Haz clic en Save.
  4. Obtener el enlace del sitio: Espera unos minutos y recarga la página hasta que aparezca la URL pública generada (ejemplo: https://tu_usuario.github.io/aux-sis313g1-i26-Ayllon_Campero_Valery_Estela/).
